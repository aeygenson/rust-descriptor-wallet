# Architecture Decision Records (ADRs)

This directory records the architectural decisions that define the current
shape of `rust-descriptor-wallet`.

The ADRs in this folder are written against the implemented codebase, not a
future roadmap. When the architecture changes materially, add a new ADR or mark
an older one as superseded instead of silently letting the record drift.

Current ADR set:

- `0001-project-architecture.md`
- `0002-psbt-first-design.md`
- `0003-coin-selection-model.md`
- `0004-backend-abstraction.md`
- `0005-storage-separation.md`
- `0006-regtest-testing-strategy.md`
